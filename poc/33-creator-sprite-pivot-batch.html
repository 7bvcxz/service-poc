스프라이트 회전축 일괄 정렬

캐릭터 애니메이션의 프레임마다 발 위치가 달라 덜컹거릴 때, 공통 기준점을 잡고 각 프레임의 피벗 좌표와 이동 보정값을 한 번에 계산해 CSV로 저장해.

3단계 사용법

① 프레임별 크기와 발 위치를 입력 → ② 공통 기준을 정하고 피벗 계산 → ③ 프레임별 보정값을 확인하고 CSV로 내보내기.

각 줄: 프레임이름,너비(px),높이(px),발X(px),발Y(px). 좌상단 (0,0), 오른쪽·아래 방향이 양수. 엔진별 Y축 방향은 다를 수 있어.

피벗 정규화 좌표 = 발 위치 ÷ 프레임 크기. 이동 보정 = 공통 기준점 − 현재 발 위치. 실제 이미지 픽셀은 변경하지 않아.

보정 결과

계산을 실행하면 결과가 나타나.
프레임피벗 X/Y정규화 X/Y이동 ΔX/ΔY

입력은 이 기기 안에서만 계산해. 원본 스프라이트 이미지 수정이나 엔진별 자동 적용은 제공하지 않아. CSV의 Δ 좌표를 엔진 설정에 맞게 적용해.
