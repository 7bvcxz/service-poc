소책자 접지 페이지 배치 계산기

소책자를 직접 인쇄하는 창작자를 위해, 페이지 수와 묶음 크기를 입력하면 양면 인쇄용 앞·뒷면 페이지 순서와 빈 페이지 수를 계산해 줍니다. 실제 프린터의 양면 뒤집기 설정은 별도 확인하세요.

  1. 1. 문서 페이지 수 입력
  2. 2. 묶음당 종이 수 선택 후 배치 계산
  3. 3. 앞·뒷면 순서를 확인하고 CSV 저장

인쇄 설정

한 장은 접으면 4페이지가 됩니다. 묶음별 최소 방식은 마지막 묶음에 필요한 종이만 사용합니다.
