러그 도안의 색 구역을 선택해 작업 순서를 정하고, 실제 도안 위에서 순서를 재생하는 오프라인 미니 도구입니다. 샘플 도안의 칸을 클릭해 색을 칠한 뒤 색상별 작업 순서를 만들어 보세요.

도안 편집

색상을 선택한 뒤 도안 칸을 눌러 수정합니다. 같은 색이 떨어져 있으면 연결된 영역마다 별도 작업 단계로 취급합니다.

작업 순서

색상 영역을 도안에서 클릭하면 작업 순서에 추가됩니다. 이미 추가된 영역은 다시 클릭하면 순서에서 제거됩니다.

    참고: 연결 영역은 상하좌우 인접 기준입니다. 실제 터프팅 작업의 재료·안전·제작 동선은 검증하지 않은 개념 POC입니다.
