CreatorFontFallbackMap

Windows · macOS · Linux의 대표적인 폰트 스택을 현재 브라우저에서 나란히 비교합니다. OS를 가상 실행하거나 설치되지 않은 폰트를 재현하지는 않습니다.

사용법과 해석

문장을 입력하고 크기·굵기·자간을 바꾸면 세 스택의 실제 렌더링과 캔버스 측정 너비가 즉시 갱신됩니다. 사용된 실제 폰트를 확정할 수는 없습니다. 브라우저가 설치된 폰트에서 순서대로 대체하므로 OS 이름은 스택의 예시일 뿐입니다.

측정값은 현재 기기의 Canvas measureText 기준이며 문자별 실제 폰트 이름을 판별하지 않습니다. CSV에는 원문, 스택, 너비, 현재 기기의 font availability 추정치가 포함됩니다. 민감한 문장을 넣지 마세요. 모든 처리는 브라우저 내부에서 이루어집니다.
