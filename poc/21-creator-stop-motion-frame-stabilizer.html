스톱모션 프레임 흔들림 정렬

고정 배경의 기준점을 찍어 프레임마다 흔들린 위치를 맞추고, 정렬된 이미지를 PNG로 저장해. 모든 처리는 브라우저 안에서만 진행돼.

3단계 사용법

① 예제 체험 또는 사진 2장 선택 → ② 각 프레임의 동일한 배경 점 클릭 → ③ 정렬 결과 비교 후 PNG 저장

두 사진은 같은 크기와 장면이어야 해. 움직이는 피사체 대신 고정 배경을 기준점으로 선택해.

기준 프레임

기준점을 클릭해 줘.

흔들린 프레임

동일한 기준점을 클릭해 줘.

사진 또는 예제를 불러와 시작해.

한 점 기준 평행이동만 보정해. 회전·줌·원근 변화나 피사체 움직임은 보정하지 않아.
